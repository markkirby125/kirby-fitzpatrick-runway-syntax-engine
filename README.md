# kirby-fitzpatrick-runway-syntax-engine

Limit introductory clauses to short, aerodynamic runways before launching main clauses to maximize cognitive momentum and reading clarity.

## Overview

The **Runway Syntax Engine** treats introductory dependent clauses as short, aerodynamic takeoff runways ($\le 5$ words) that launch directly into the primary main clause, eliminating 30-word preamble sentences and attention drag in technical explanations.

## Core Patterns

- **The 5-Word Runway Limit**: Restrict pre-subject modifiers to 5 words or fewer.
- **Preamble Severing**: Sever long preambles into standalone sentences or trailing qualifications.
- **Direct Zero-Word Launch**: Start directly with the subject whenever context allows.
